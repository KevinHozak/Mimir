The recorded interpretation table separately contains five AI and 891 rules interpretations. These counts describe different records and should not be added as a decision total.

The same timeline held eight completed, two active and one interrupted goal at pulse 150. At pulse 290 it held 32 completed, six active and three interrupted. The recovered last three pulses add the two rules exploration completions and Spark 2's shaping completion, with the final active and interrupted counts unchanged. This is a within-run comparison. Population, available alternatives, runtime policies and exposure time varied, so the source totals cannot establish comparative model benefit. The [ordinary-history comparison](s022-ordinary-history-comparison-2026-11-20.md) compares four recorded histories at pulse 293. A matched test of model benefit remains open. The expired and unfinished examples above stay in the evidence set.

Both SQLite databases passed integrity checks in read-only mode. The analysis verified all 64 stored goal-step completion references against objective event IDs and pulses, reconciled the stored goal receipts by request ID, and checked every report route against the recovered timeline. This is technical evaluation of recorded outcomes. Human usability, interest and acceptance belong to S023.

The pilot stayed stopped. The analysis used no provider calls or cloud operations and incurred no additional spending.
