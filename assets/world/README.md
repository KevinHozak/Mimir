# World map sources

`first-winter.tiled.json` is the initial authored orthogonal map source for the structured world pipeline. It uses a 24-pixel grid and the following provisional tile mappings used by the importer fixture:

- GID 1: grass
- GID 2: water
- GID 3: road

The map contains a house, tree, granary, and bridge object layer. The current renderer uses the normalized object definitions and procedural placeholder colors while final licensed tileset art is selected. Keep the source map and its eventual tileset provenance together when the art is replaced.
